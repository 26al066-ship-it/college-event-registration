# 🎓 College Event Registration Form

## 📌 Project Description
The College Event Registration Form is a web-based application developed using HTML5 and CSS3. It allows students to register for various college events by entering their personal details and selecting their preferred events.

## 🎯 Objectives
- To create a user-friendly event registration form.
- To collect student information.
- To provide different event options.
- To apply HTML5 form validation.
- To design an attractive and responsive webpage using CSS3.

## 🛠️ Technologies Used
- HTML5
- CSS3

## ✨ Features
- Student personal details.
- Email and mobile number validation.
- Department selection.
- Year of study selection.
- Gender selection.
- Multiple college event options.
- Event date selection.
- Food preference selection.
- Terms and conditions checkbox.
- Submit and Reset buttons.
- Responsive design.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate the index.html file.
4. Double-click index.html.
5. The registration form will open in your web browser.

## 📸 Output
The webpage displays a student registration form with personal details, event selection, and registration buttons.
